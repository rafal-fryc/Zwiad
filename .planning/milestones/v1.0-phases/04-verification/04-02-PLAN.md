**1. Create `pipeline/scripts/run-reviewer.sh`:**

Follow the `run-researcher.sh` pattern for script structure (SCRIPT_DIR, PROJECT_ROOT, RUN_ID argument, per-finding loop).

```bash
#!/bin/bash
set -euo pipefail
```

**Usage:** `run-reviewer.sh <run-id>`

**Input:** Reads `$RUN_DIR/researcher-output.json` (or individual `researcher-$FINDING_ID.json` files) to get the list of reports to review. The researcher output contains `data.reports[]` with `finding_id` and `report_path`.

**Script structure:**

a) **Setup:** Parse RUN_ID argument. Set RUN_DIR. Validate researcher output exists.

b) **Collect reports to review:** Use jq to extract `finding_id` and `report_path` from researcher output files. For each `researcher-*.json` in the run directory, extract the reports array.

c) **Per-report review loop:**
```
for each (FINDING_ID, REPORT_PATH) from researcher outputs:
  # T-04-02: Validate report_path starts with reports/(privacy|cybersecurity|ai-law)/
  if [[ ! "$REPORT_PATH" =~ ^reports/(privacy|cybersecurity|ai-law)/ ]]; then
    echo "ERROR: Invalid report path: $REPORT_PATH" >&2
    continue
  fi
  
  ROUND=1
  VERIFIED=false
  
  while [ "$ROUND" -le 3 ]; do
    FEEDBACK_FILE="$RUN_DIR/reviewer-feedback-r${ROUND}-${FINDING_ID}.json"
    
    # Build reviewer prompt
    PROMPT="Review the report at $REPORT_PATH for finding $FINDING_ID."
    PROMPT="$PROMPT Pipeline run: $RUN_ID. Round: $ROUND."
    PROMPT="$PROMPT Write your feedback to: $FEEDBACK_FILE."
    
    if [ "$ROUND" -gt 1 ]; then
      PREV_REVISION="$RUN_DIR/researcher-revision-r$((ROUND-1))-${FINDING_ID}.json"
      PROMPT="$PROMPT Previous revision response at: $PREV_REVISION."
    fi
    
    # Invoke reviewer agent
    claude -p --agent reviewer \
      --output-format json \
      --max-turns 25 \
      "$PROMPT"
    
    # Check feedback file exists
    if [ ! -f "$FEEDBACK_FILE" ]; then
      echo "WARNING: Reviewer did not produce feedback for $FINDING_ID round $ROUND" >&2
      break
    fi
    
    # Validate feedback against schema (T-04-01)
    if ! jq -e -f "$PROJECT_ROOT/pipeline/schemas/reviewer-feedback.jq" "$FEEDBACK_FILE" >/dev/null 2>&1; then
      echo "WARNING: Feedback validation failed for $FINDING_ID round $ROUND" >&2
      break
    fi
    
    # D-06: Check for critical/major issues
    CRITICAL_MAJOR=$(jq '[.issues[] | select(.severity == "critical" or .severity == "major")] | length' "$FEEDBACK_FILE")
    
    if [ "$CRITICAL_MAJOR" -eq 0 ]; then
      echo "Round $ROUND: Resolved for $FINDING_ID (minor issues only)"
      VERIFIED=true
      break
    fi
    
    echo "Round $ROUND: $CRITICAL_MAJOR critical/major issues for $FINDING_ID"
    
    # D-09: If round 3, escalate
    if [ "$ROUND" -eq 3 ]; then
      echo "Escalating $FINDING_ID after 3 rounds"
      "$SCRIPT_DIR/generate-escalation.sh" "$RUN_ID" "$FINDING_ID" "$REPORT_PATH"
      break
    fi
    
    # Invoke researcher for revision
    REVISION_FILE="$RUN_DIR/researcher-revision-r${ROUND}-${FINDING_ID}.json"
    REVISION_PROMPT="Revise the report at $REPORT_PATH based on reviewer feedback."
    REVISION_PROMPT="$REVISION_PROMPT Read feedback at: $FEEDBACK_FILE."
    REVISION_PROMPT="$REVISION_PROMPT Address each issue. Write revision response to: $REVISION_FILE."
    REVISION_PROMPT="$REVISION_PROMPT Pipeline run: $RUN_ID. Round: $ROUND."
    
    claude -p --agent researcher \
      --output-format json \
      --max-turns 20 \
      "$REVISION_PROMPT"
    
    if [ ! -f "$REVISION_FILE" ]; then
      echo "WARNING: Researcher did not produce revision response for $FINDING_ID round $ROUND" >&2
      break
    fi
    
    ROUND=$((ROUND + 1))
  done
  
  # Record review result for this finding
  # Build per-finding result: status, iteration_count, claims_checked, issues_found
  # Status: "verified" if VERIFIED=true, "needs-human-review" if escalated (round==3 and not verified)
  
  # ... (collect into REVIEWS_JSON array)
done
```

d) **Build final reviewer output envelope:**
After processing all findings, build the `reviewer-output.json` envelope wrapping all review results:
```bash
jq -n \
  --arg run_id "$RUN_ID" \
  --arg status "$OVERALL_STATUS" \
  --argjson reviews "$REVIEWS_JSON" \
  '{
    schema_version: "1.0",
    pipeline_run_id: $run_id,
    timestamp: (now | todate),
    stage: "reviewer",
    status: $status,
    data: { reviews: $reviews }
  }' > "$RUN_DIR/reviewer-output.json"
```

Where `$OVERALL_STATUS` is:
- `"complete"` if all reports verified (D-11: auto-pass to categorizer)
- `"pending-review"` if any report needs human review

e) **Validate output:** Run `validate-handoff.sh reviewer "$RUN_DIR/reviewer-output.json"`

f) **Print summary:** Success/failure/escalation counts. Next step message: "Next: Run categorizer agent." or "Next: Resolve escalations in $RUN_DIR/reviewer-escalation-*.md"

Make the script executable: `chmod +x pipeline/scripts/run-reviewer.sh`

**2. Create `pipeline/scripts/generate-escalation.sh`:**

```bash
#!/bin/bash
set -euo pipefail
```

**Usage:** `generate-escalation.sh <run-id> <finding-id> <report-path>`

**Reads:** All `reviewer-feedback-r*-${FINDING_ID}.json` and `researcher-revision-r*-${FINDING_ID}.json` files from the run directory.

**Writes:** `$RUN_DIR/reviewer-escalation-${FINDING_ID}.md`

**Script logic:**
- Collect all round files for the finding
- Extract unresolved issues (status == "open" or "upheld") from the final round's feedback
- For each unresolved issue, compile round-by-round history from all feedback and revision files
- Generate markdown following this structure:

```markdown
# Verification Escalation

**Pipeline Run:** {RUN_ID}
**Finding:** {FINDING_ID}
**Report:** {REPORT_PATH}
**Rounds Completed:** 3

## Unresolved Issues

### Issue 1: [{severity}] {claim summary}

**Reviewer's Concern:** {issue description from latest feedback}
**Researcher's Response:** {justification from latest revision, or "No response" if not disputed}

**Round History:**
- Round 1: Raised by reviewer
- Round 2: {Disputed/Fixed/etc} by researcher -- {detail}
- Round 3: {Upheld/etc} by reviewer -- {detail}

[... repeat for each unresolved issue ...]

## Current Report

See: {REPORT_PATH}

## Instructions

Review the unresolved issues above. Edit the report file directly to resolve them.
When complete, add the marker below (uncomment it):

<!-- ## APPROVED -->
```

Make executable: `chmod +x pipeline/scripts/generate-escalation.sh`
