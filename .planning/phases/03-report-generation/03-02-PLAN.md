**pipeline/scripts/run-researcher.sh** -- Follow run-scanner.sh pattern exactly:

```bash
#!/bin/bash
set -euo pipefail
```

1. SCRIPT_DIR and PROJECT_ROOT resolution (same as run-scanner.sh)
2. Accept RUN_ID as first required argument: `RUN_ID="${1:?ERROR: Must provide run-id as first argument}"`
3. Set `RUN_DIR="$PROJECT_ROOT/pipeline/runs/$RUN_ID"` and `APPROVED_FILE="$RUN_DIR/scanner-approved.json"`
4. Validate APPROVED_FILE exists, exit 1 if not
5. Count findings: `FINDING_COUNT=$(jq '.data.findings | length' "$APPROVED_FILE")`
6. Print "Processing $FINDING_COUNT approved findings..."
7. Loop `for i in $(seq 0 $((FINDING_COUNT - 1))); do`:
   a. Extract FINDING_ID: `jq -r ".data.findings[$i].id" "$APPROVED_FILE"`
   b. Print "Researching finding $((i+1))/$FINDING_COUNT: $FINDING_ID"
   c. Build PROMPT: "Research finding index $i from $APPROVED_FILE. Pipeline run ID: $RUN_ID. Write your output metadata to: $RUN_DIR/researcher-$FINDING_ID.json. Write the report to the appropriate reports/{category}/ directory."
   d. Invoke: `claude -p --agent researcher --output-format json --max-turns 30 "$PROMPT"`
   e. Set OUTPUT="$RUN_DIR/researcher-$FINDING_ID.json"
   f. Check OUTPUT file exists, warn and continue if not
   g. Validate: `"$PROJECT_ROOT/pipeline/scripts/validate-handoff.sh" researcher "$OUTPUT"`
   h. T-03-03 mitigation: Validate report_path starts with "reports/" and category is one of privacy/cybersecurity/ai-law:
      ```bash
      REPORT_PATH=$(jq -r '.data.reports[0].report_path' "$OUTPUT")
      if [[ ! "$REPORT_PATH" =~ ^reports/(privacy|cybersecurity|ai-law)/ ]]; then
        echo "ERROR: Invalid report path: $REPORT_PATH" >&2
        exit 1
      fi
      ```
   i. Track success count
8. After loop: print summary (N of M findings researched successfully)
9. Print "Next: Run reviewer agent." as next-step hint
10. Make executable: `chmod +x`
